Flipper Zero Bluetooth

STM32WB55 punya radio BLE. Di firmware official, BLE dipakai utama untuk koneksi ke aplikasi mobile (Flipper Mobile App) dan qFlipper via BLE serial.

Official Use

  • Mobile App link BLE serial
  • Firmware update (partial) via app
  • File transfer limited
  • Remote control UI app side

Community FAP

  • BLE Spam Momentum / Unleashed
  • BT Serial tools custom
  • Apple / Android juice advertising
  • Device finder style name spam

BLE Spam (Community Firmware)

Beberapa custom firmware (Momentum, Unleashed, RogueMaster) menyertakan aplikasi BLE Spam / Continuity / Fast Pair advertising.

  • Apple Continuity / Nearby Action popup di iPhone
  • Android Fast Pair popup di Pixel / Samsung
  • Windows Swift Pair toast di Windows
  • Samsung Buds / Easy Setup popup

Lokasi di firmware: biasanya di bawah Apps → Bluetooth → BLE Spam atau serupa. Tidak ada di official stable.

Cara aktifkan (community FW)

# Contoh alur (Momentum / Unleashed) 1. Flash custom firmware (qFlipper atau .tgz) 2. Pastikan SD card ada asset / apps terbaru 3. Buka Apps → Bluetooth → BLE Spam 4. Pilih target protocol (Apple / Android / Windows) 5. Start advertising 6. Device sekitar akan dapat popup / notification # Stop: tekan Back di Flipper

Advertising Packet Structure (ringkas)

BLE advertising PDU berisi header + payload. Payload biasanya:

  • Flags (LE General Discoverable, etc.)
  • Complete / Shortened Local Name
  • Service UUIDs (16-bit / 128-bit)
  • Manufacturer Specific Data Company ID + data

Manufacturer Specific — pola umum

// Struktur kasar Manufacturer Specific Data Company ID : 2 bytes (little-endian) // e.g. Apple 0x004C Type / Model : 1+ bytes // continuity type Payload : variable // action, device info // Apple Continuity contoh (disederhanakan) Company = 0x004C Type = Nearby Action / Proximity Pairing Action = 0x0F / 0x05 / dll (tergantung popup)

Yang bisa dilakukan Flipper (community)

  • Broadcast nama device palsu name spam
  • Trigger Continuity popup (Apple) FAP
  • Trigger Fast Pair (Android) FAP
  • Trigger Swift Pair (Windows) FAP
  • Random MAC per packet (beberapa build) anti-filter

Flipper tidak punya full BLE stack untuk arbitrary GATT server / complex MITM dari stock. Untuk itu biasanya pakai nRF52 / ESP32 / laptop + tools terpisah.

Catatan legal & praktis

Advertising di ruang publik bisa dianggap gangguan. Di beberapa negara spam BLE yang menyebabkan notifikasi berulang sudah masuk kategori interference. Pakai di lab / perangkat sendiri.

GAP Roles

  • Broadcaster advertise only
  • Observer scan only
  • Peripheral advertise + connect
  • Central scan + connect

Common 16-bit UUIDs

  • 0x1800 Generic Access
  • 0x1801 Generic Attribute
  • 0x180A Device Information
  • 0x180F Battery Service
  • 0xFE2C Fast Pair (Google)

Company Identifiers (penting)

  • 0x004C Apple, Inc.
  • 0x0006 Microsoft
  • 0x00E0 Google
  • 0x0075 Samsung Electronics
  • 0x00D2 Google (Fast Pair related)
